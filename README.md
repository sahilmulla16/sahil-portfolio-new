# Sahil Portfolio (Full)

## Quick start

1. Install dependencies

```
npm install
```

2. Run dev server

```
npm run dev
```

Notes:
- Tailwind requires PostCSS – already configured in postcss.config.cjs and tailwind.config.cjs.
- The Three.js scene is lightweight (icosahedron). If you want the iPhone mock later, tell me and I'll swap it.
